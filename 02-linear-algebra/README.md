# 线性代数：先看见，再算明白

线性代数不需要先学会导数、积分。只要能做加减乘除、解二元一次方程，就可以开始。这里用“箭头怎样组合”“平面怎样变形”解释概念，再把直觉翻译为考试可以写出的公式和步骤。

本目录是原创入门讲义，不是教材逐页复刻，也没有上传你提供的 PDF。例题与练习均为本仓库设计；同济教材用于核对知识范围，几何读物用于确定“先直观后抽象”的学习方向。**直觉帮助理解，定义和条件负责保证结论正确。**

## 一次学习怎样安排

1. 用 5 分钟读目标和符号表。遇到不懂的符号，先回表格，不要靠猜。
2. 用 15–25 分钟读一个知识块和一条例题。拿纸重算每一步，在旁边写“这一步用了什么规则”。
3. 盖住例题答案，独立重做。看到答案觉得懂，和自己能够算出来，是两件事。
4. 做两道练习。卡住超过 10 分钟，先写出已知量、要求量、可能用的定义，再看对应答案。
5. 把错因记为“概念条件 / 维数 / 计算 / 符号 / 参数漏分情况”之一。第二天只重做做错的题。

可以每周完成一章，也可以一章分三晚。开始时做对 1、2 题就继续练基本运算；不必一次做完提高题。第一次学习建议留 6–8 周，进度以过关标准为准。

## 通用记号与检查习惯

- 全部默认在实数范围讨论，特殊例子会说明复数情况。向量默认写成列向量。
- $A^T$ 表示转置；$I_n$ 是 $n$ 阶单位矩阵；$0$ 根据上下文是零数、零向量或零矩阵，必须核对尺寸。
- $A^{-1}$ 是逆矩阵，只有可逆方阵才有；$|A|$ 或 $\det A$ 是行列式，是一个数。
- 动笔先写尺寸：例如 $A$ 是 $2\times3$，那么 $Ax$ 的输入是三维向量，输出是二维向量。
- 每个解尽量代回原问题。求逆后乘一次，求特征向量后算一次 $Av$，求方程组解后逐行代入。
- 带参数的题，在除以某个含参数的式子前，先讨论它是否等于零。

## 完成本轮后的选择

先能熟练解小规模方程组，再加大矩阵尺寸。学校若要求抽象线性空间、坐标变换、分块矩阵、向量内积的完整理论，可按教材继续补充；本轮覆盖的是入门核心，并不声称代替全部课程或所有考试范围。
