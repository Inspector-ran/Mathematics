这里的题目是基础到进阶的过渡，不冒充学校真题或竞赛原题。需要竞赛训练时，先掌握一元微积分主线，再按竞赛教程的专题继续。上册的题目范围与本仓库全部内容不完全相同，见书目说明。

练习答案与题目分开保存。完成以后不仅核对数字，还要检查定义域、分类条件、证明理由和是否给出了全部解。
