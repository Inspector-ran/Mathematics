# 看见题目以后，怎样选择方法

[练习区](README.md) · [综合题](bridge-problems.md)

这份指南用于整理思路。它是方法提示，不是看到某个关键词就一定能套用的规则。正式作答前，总要把条件和对象写清楚。

## 1. 极限：先识别未定式

先代入或观察，判断是正常连续代入、$0/0$、$\infty/\infty$，还是乘积、差式等其他形式。

| 结构 | 优先尝试 | 必须检查 |
|---|---|---|
| 多项式同时为零 | 因式分解、约分 | 邻近点分母不为零 |
| 根式之差 | 有理化 | 共轭式与根号定义域 |
| $\sin x/x$ 等基本结构 | 提取比例、使用基本极限 | 三角函数使用弧度 |
| 一阶项抵消 | 泰勒展开到足够阶数 | 余项相对分母确实趋零 |
| 符合条件的 $0/0$ 或 $\infty/\infty$ | 洛必达法则 | 可导、分母导数非零、导数比极限 |
| 左右表达式不同 | 分别求左右极限 | 两侧是否一致 |

不要连续机械求导却不判断条件；也不要把等价无穷小直接放进有抵消的加减式。

## 2. 导数应用：把“候选”与“结论”分开

求单调性：定义域 → 导数 → 分界点 → 各区间符号 → 单调区间。

求闭区间最值：确认连续 → 内点驻点和不可导点 → 端点 → 比较函数值。只算导数为零会遗漏端点；导数为零也不自动代表极值。

证明不等式：可尝试把两边移到一边构造函数，研究符号或单调性；出现两个点的函数差，可以检查中值定理。每种方法都应说明适用区间。

## 3. 积分：先看是否能简化

1. 有分式，先试代数整理、因式分解或拆分。
2. 复合函数外面出现内层导数，考虑换元。
3. 多项式乘指数、三角、对数，考虑分部积分，并观察剩余积分是否更简单。
4. 有上下限，利用对称性前先检查整个区间。
5. 反常积分先分开奇点，再分别判断；不能用两边“正负抵消”代替收敛。
6. 二重积分先画区域。内层难积时，检查能否换序；圆形结构考虑极坐标。

不定积分答案求导检查；定积分检查数量级、符号和区间长度。定积分换元时，变量与上下限同时更换，不能混用。

## 4. 线代：先写尺寸，后写运算

| 题目任务 | 主线 | 最后核对 |
|---|---|---|
| 解方程组 | 增广矩阵行变换、秩与自由变量 | 代回原方程 |
| 判断相关 | 设线性组合为零，或用秩 | 系数是否不全为零 |
| 求逆 | 先判可逆，再用公式或消元 | 乘回单位矩阵 |
| 行列式 | 零多则展开，否则考虑行变换 | 换行符号、倍乘系数 |
| 特征值与向量 | 特征方程，再解齐次方程 | $Av=\lambda v$ 且 $v\ne0$ |
| 对角化 | 找足够多独立特征向量组成 $P$ | $AP=PD$，$P$ 可逆 |
| 正定性 | 实对称矩阵、特征值或顺序主子式 | 严格正与非负别混淆 |

含参数时，把“要除以的量等于零”单独讨论。方程个数不等于秩，重复约束不会增加独立信息。

## 5. 怎样检查答案而不从头再算一遍

- 代回：特解、微分方程和特征向量最适合。
- 求导：验证原函数，检查积分因子求解得到的函数。
- 看符号：非负函数在正常方向区间上的积分不能为负。
- 看特殊值：参数取零、一或边界值时是否符合原题。
- 看尺寸：向量、矩阵乘积和标量不能混淆。
- 看全部情况：端点、奇点、参数零值、自由变量有没有遗漏。

这些检查会发现许多错误，但少量数值检验不能证明对所有输入都正确。证明题仍需给出一般理由。

## 6. 限时练习后的复盘

把失分按“不会选方法、公式条件不清、计算失误、表达不完整、时间不足”分开。每次只挑最影响结果的一类改进：

- 不会选方法：比较两道外形不同、核心相同的题。
- 条件不清：为公式补一个反例。
- 计算失误：把容易漏的中间步骤写出来。
- 表达不完整：照定义补齐“为什么”。
- 时间不足：先确保方法正确，再用已经会的题练熟练度。

不要只抄标准答案。能指出自己的第一处错误，并在隔天不看解析重做，才完成了一次有效复习。
