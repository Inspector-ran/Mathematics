# Mathematics｜数学学习手册

从基础补习开始，逐步学会高等数学与线性代数。讲解使用中文，重视“这个符号是什么意思、为什么这样算、什么时候才能用”。

**第一次来，请打开 [完整使用指南](START-HERE.md)，再做 [20～30 分钟入门自测](00-foundations/diagnostic.md)。** 不必一次读完；今天学懂一个小节、独立完成两道题，就可以记录进度了。

## 推荐学习路线

高数第一轮先走主线：

**代数与函数 → 极限 → 导数 → 导数应用 → 不定积分 → 定积分。**

随后可学常微分方程；多元微分、重积分、级数、曲线曲面积分按学校进度继续。线代可以与高数并行：

**向量 → 矩阵 → 行列式 → 消元与秩 → 特征值 → 二次型。**

学校从行列式开课也没关系，先读线代第 3 章的计算，再补前两章的直觉。具体节奏见[学习计划](STUDY-PLAN.md)。

## 一章怎样使用

1. 检查前置知识，圈出不熟的符号。
2. 读一个知识块，写清定义、条件和用途。
3. 遮住例题解答，在纸上重做。
4. 先完成基础练习，再打开该章 solutions 解析。
5. 把错因写成一句可行动的提醒，隔天重做。

“看懂答案”是起点；能独立写出理由、发现不满足条件的情形，才算更稳。遇到困难先定位到具体一步，不必给自己贴标签。

## 阅读与保存

直接点击 GitHub 中的 Markdown 文件即可阅读数学公式，无需安装编译器。每章的答案在对应 solutions 目录。首页 Code → Download ZIP 可下载全部内容；离线阅读需要支持数学公式的 Markdown 阅读器。

图解集中在 assets 目录，均为本仓库原创。练习需要自己书写，仓库不会自动评分。详细操作、每日安排、公式记忆方法见[使用指南](START-HERE.md)。

## 本版范围

本版是高等数学和线性代数的详细入门手册。每章覆盖核心概念，并用少量进阶内容连接后续学习。曲线曲面积分、二阶微分方程等已明确分层；傅里叶级数、复变函数、积分变换、概率统计和更抽象的线性空间理论尚未展开，不能把本版当作学校全部“工程数学”课程范围。

按你提供的四本 PDF 核对了目录与知识对应关系，正文与题目独立编写。仓库不包含原书 PDF 或书页扫描件；阅读参考书时请使用自己已有的资料。发现错误可在对应笔记记录题号、原式和检查过程，再修正讲义与答案。

本版完成的计算与文档检查见[检查记录](VALIDATION.md)。
